NovaOS built-in bitmap font — licence notice
=============================================

What this file covers
---------------------

The glyph designs baked into `crates/nova-ui/src/font.rs`: the 8x16 bitmaps
for ASCII 32 through 126 that NovaOS draws text with at milestone M6 (see
`reports/NovaOS.md` §15.4, "文本与字体").

Those bitmaps are rasterisations of **DejaVu Sans Mono**, which in turn
derives its glyph designs from **Bitstream Vera Sans Mono**. DejaVu's own
changes are in the public domain; the Vera designs are not, and they travel
under the permission notice reproduced below. NovaOS redistributes derived
copies, so the notice ships with them — which is the whole reason this file
exists.

Nothing else in the repository is under this licence. The NovaOS source is
under the repository's own licence; only the font data is Bitstream's.

Modification
-----------

The glyphs have been modified: they are rasterised at 13 pixels with a fixed
baseline into an 8x16 cell and thresholded to one bit per pixel, so they are
bitmap representations rather than outlines, and a program cannot recover the
original outlines from them. `tools/gen_font.py` is the script that performs
the rasterisation.

Rename requirement
------------------

The Vera permission notice allows modification only if the result is renamed
to a name that does not contain "Bitstream" or "Vera". The derived font is
called the **NovaOS built-in bitmap font**, lives in the module `nova_ui::
font`, and contains neither word. The notice below therefore stays in force.

Provenance
----------

- DejaVu Sans Mono: https://dejavu-fonts.github.io/
  Debian package `fonts-dejavu-core`, file `usr/share/fonts/truetype/
  dejavu/DejaVuSansMono.ttf`.
- Bitstream Vera Sans Mono: the typeface DejaVu is derived from.
